# Android 防烧屏动态保护（OLED Motion Guard）

给 spacedesk 安卓客户端、远程桌面、监控面板、电子看板等长时间静态显示场景使用的透明动态悬浮层。它在手机上作为前台服务运行，按间隔短暂覆盖当前画面，播放移动的彩色纸带、彩虹、纸屑或柔和彩色方块。

它不是只给 spacedesk 用的，也不是百分之百防止 OLED 烧屏的工具；它的作用是让覆盖期间的显示像素产生变化，作为降低长时间静态显示风险的辅助措施。

## 下载

已发布的 APK 在 GitHub 的 [Releases](../../releases) 页面。当前 APK 面向 Android 11 及以上，包含 32 位兼容性验证。

## 使用

1. 安装 APK。
2. 打开应用，点击“允许悬浮窗权限”，在系统设置中允许“显示在其他应用上层”。
3. 设置间隔、持续时间、透明度和动画模式。
4. 点击“启动定时保护”。首次可以点“立即测试”确认效果。
5. Android 会显示一个常驻通知，这是维持后台定时器和悬浮层的必要条件。

默认优先考虑低亮度和较低透明度。这个覆盖层不能移动底层 spacedesk 画面里的静态 UI，只能让覆盖时的屏幕像素产生变化；仍应配合手机系统的自动息屏、像素移位和较低亮度功能。
