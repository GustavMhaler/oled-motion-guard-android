# 安卓防烧屏小工具：让长时间不动的 OLED 屏幕定时“动一下”

我把手机当作电脑的副屏使用，最开始用的是 spacedesk。手机屏幕是 AMOLED，真正让我在意的不是分辨率，而是一个很朴素的问题：如果副屏长时间停在同一个画面上，会不会增加烧屏风险？

于是我做了一个 Android 小工具，名字叫 **OLED 动态保护**。

它不修改 spacedesk，也不需要电脑端配合。它运行在手机上，用一个低透明度的动态悬浮层，隔一段时间在当前画面上播放几秒彩色动画，然后自动隐藏。除了 spacedesk，它也适用于其他长时间显示静态内容的场景。

## 它解决的是什么问题？

OLED 屏幕的每个像素都会随着使用时间老化。不同区域如果长期显示差异很大的固定内容，老化速度可能不一致，最后表现为残影、色差或局部亮度不均。大家通常把这种现象叫“烧屏”。

这不是说画面静止几分钟就一定会烧屏，也没有一个适用于所有手机的固定时间阈值。屏幕亮度、显示内容、使用时长、面板寿命和厂商的像素补偿策略都会影响结果。

所以这个工具的定位很明确：**降低长时间静态显示的风险，不能保证完全避免烧屏。**

## 它是怎么工作的？

工具使用 Android 的“显示在其他应用上层”权限，在当前应用上方添加一个不可触摸的透明悬浮层。

默认情况下，悬浮层不会一直挡住内容，而是按照设置的间隔短暂出现。例如：

- 每 10 分钟播放一次
- 每次播放 20 秒
- 使用 15%～25% 的透明度
- 播放结束后自动隐藏

目前有四种动画：

1. **彩色纸带**：几条缓慢移动的彩色曲线，适合日常使用。
2. **彩虹洗屏**：全屏缓慢移动的彩虹色带。
3. **彩色纸屑**：彩色小方块从屏幕上飘落。
4. **柔和彩色方块**：低亮度色块缓慢变化。

动画本身没有交互功能，也不会抢走当前应用的焦点。它只是短暂改变屏幕上呈现的像素。

## 不只是 spacedesk

最初的使用场景是把手机当副屏，但只要是“长时间显示、画面变化很少”的场景，都可以尝试：

- spacedesk 手机副屏
- Android 远程桌面
- 长时间打开的监控面板
- NAS、服务器或智能家居仪表盘
- 电子看板和信息展示屏
- 长时间停留的文档、表格或代码画面
- 投屏接收端或远程操作画面
- 需要持续显示的自制 Android 终端

不建议在驾驶导航、医疗监测、游戏竞技或任何不能被短暂遮挡的场景中使用。透明度虽然很低，但它毕竟会在画面上出现动态色彩。

## 手机上怎么用？

1. 安装 APK。
2. 打开工具，允许“显示在其他应用上层”。
3. 允许通知权限。
4. 设置间隔、持续时间、透明度和动画模式。
5. 点击“立即测试一次”，确认效果。
6. 点击“启动定时保护”。

Android 会保留一个前台服务通知，这是为了让系统知道工具正在运行，减少它被后台清理的机会。部分小米、OPPO、vivo 等系统还需要把应用的电池策略改成“不限制”，并允许自启动。

## 这个工具不能做什么？

这里需要把边界说清楚。

它不能移动底层应用的 UI，也不能修改 spacedesk 传输过来的画面。它做的是在画面上方添加一个会移动的低透明度图层。因此：

- 它不是像素级的真正“屏幕平移”。
- 它不能保证彻底防止 OLED 烧屏。
- 它不能替代手机系统自带的像素移位、屏幕保护和自动息屏。
- 如果手机长期以很高亮度显示固定白色元素，仍然存在风险。

更稳妥的做法是一起使用：降低亮度、使用深色主题、缩短自动息屏时间、开启系统像素移位功能，并避免让固定 Logo 或高亮白色界面长时间停留在同一位置。

## 最后

我做这个工具的原因很简单：手机 AMOLED 屏幕越来越适合拿来当副屏、信息面板和远程终端，但很多时候我们只关注“能不能显示”，很少关注“固定显示几小时会怎样”。

定时让画面短暂动一下，成本很低，也不会改变原来的使用方式。如果你的手机经常显示固定的远程桌面、监控面板或副屏内容，可以试试；如果你的场景不能被短暂遮挡，那就不要开启它。

它不是万能的防烧屏方案，但至少可以成为日常使用中的一个小保护措施。
